# 规格：arm-cpu — 客户机 ARM 原生代码执行内核

本能力规定 MRP 原生扩展二进制在客户机地址空间内的 ARM 代码执行行为。
对外契约以 guest 二进制的可观测结果为准：寄存器/标志终态、内存读写效果、
主机服务调用触发、错误报告。

## 新增需求

### 需求:完整的 ARMv4T 指令语义
运行时必须按 ARMv4T 架构语义执行客户机二进制中的 ARM 状态（A32）指令与
Thumb 状态指令，包括乘累加、长乘、半字/有符号字节传输、块传输、交换、
PSR 访问以及全部数据处理的移位器与标志行为。遇到未定义或超出 ARMv4T 的编码时，
运行时禁止静默跳过，必须产生显式错误并终止当前客户机执行。

#### 场景:ARM 与 Thumb 状态切换
- **当** 客户机代码通过 BX 指令在 ARM 状态与 Thumb 状态之间切换
- **那么** 后续取指按目标状态宽度解码执行，且 CPSR 的 T 位可观测地反映当前状态

#### 场景:超出架构的编码报错
- **当** 客户机执行的指令编码未定义或属于未实现的架构扩展
- **那么** 运行时返回携带 PC 与指令字的 ArmFault 错误，不继续执行后续指令

### 需求:条件执行与标志一致性
除无条件类指令外，所有 A32 指令必须在条件字段判定后决定是否生效；
N/Z/C/V 标志的设置规则必须与架构参考一致，Thumb 状态下数据处理与比较指令
相应更新 N/Z（及进位/借位）标志。

#### 场景:条件不满足则无副作用
- **当** 一条条件码判定失败的 A32 指令被取出
- **那么** 除 PC 推进外不产生任何寄存器、标志或内存副作用，且消耗一条指令预算计数

### 需求:经权限检查的客户机内存总线访问
CPU 的全部取指与数据访问必须经由带分区权限模型的客户机内存（GuestMemory）
完成。读操作要求 READ 权限，写操作要求 WRITE 权限；访问未映射区域或越权访问时，
运行时必须记录故障上下文（地址、访问类型、PC）并返回显式错误，
禁止静默回绕或忽略。

#### 场景:未映射访问失败
- **当** 客户机代码读取一段未映射的地址
- **那么** 当前执行返回包含该地址与访问类型的错误，宿主收到而非丢失

#### 场景:只读区写入失败
- **当** 客户机代码向仅有 READ 权限的映射写入数据
- **那么** 写入不生效且执行以越权访问错误终止

### 需求:主机扩展陷阱弹床
对位于陷阱窗口（0xFF000000 起的槽位）的调用指令，客户机的可观测行为必须是
一次普通的子程序调用：进入陷阱槽后执行立即返回到链接寄存器指向的地址，
而主机侧在该边界派发对应的 EXT 服务槽位。该窗口的取指内容不得泄露为
真实代码页，且不得依赖任何特定样本的硬编码分派路径。

#### 场景:扩展调用往返
- **当** 客户机函数通过 BL 进入陷阱窗口中的一个槽位地址
- **那么** 对应 EXT 服务被派发，随后客户机从 BL 下一条指令继续，
  r0 返回值与服务实现约定一致

#### 场景:未知槽位拒绝
- **当** 客户机调用的陷阱槽编号未被派发表支持
- **那么** 运行时返回携带模块号、槽号与 LR/r0-r3/sp 上下文的错误

### 需求:SWI 半宿主出口语义
当客户机执行注释值为 0x123456 的 SWI 且 r0 为 0x18 时，运行时必须将该请求
识别为半宿主退出，把 r1 作为退出原因传递给宿主并停止客户机执行；
r0 为其他值的同类 SWI 由宿主钩子接管处理。ARM 与 Thumb 两种状态下的
SWI 编码都必须得到一致的对待。

#### 场景:semihosting 出口
- **当** guest 在任一指令状态下执行 `swi #0x123456` 且 r0==0x18、r1=原因值
- **那么** 运行时将该原因上报宿主出口通道，客户机执行结束

### 需求:固定预算下的确定性执行
每次客户机调用受统一的指令预算约束；超预算必须以显式错误终止。
对相同的输入镜像与事件序列，寄存器可见状态、内存映像和输出帧必须逐位确定，
不受宿主调度或环境噪声影响。

#### 场景:预算耗尽报错
- **当** 单次客户机调用执行的指令数达到上限仍未返回
- **那么** 执行以预算耗尽错误终止，已发生的内存副作用保持可观测

### 需求:指令级追踪开关的存在性
当且仅当设置了 SKYENGINE_TRACE_ARM 环境变量时，运行时输出每步的指令级轨迹
供调试；未设置时禁止产生此类输出以保证确定性。

#### 场景:默认静默
- **当** 未设置 SKYENGINE_TRACE_ARM 并执行任意客户机程序
- **那么** 不产生每指令日志输出
